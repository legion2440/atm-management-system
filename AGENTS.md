# Repository guidance

This repository follows a small repo-local workflow.

1. Read this file and `agent/module-index.md` before changing code.
2. Open only the module(s) relevant to the task; do not scan unrelated files without need.
3. Treat production code and executable test evidence as authoritative over README prose.
4. Keep the 01-edu ATM assignment behavior in scope; avoid unrelated product features.
5. Run `make verify` after functional changes and `make check` before publishing.
6. Keep data-file compatibility unless a change explicitly targets storage.
